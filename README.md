# 공시루틴 — 3일 단위 유연형 공부 플래너

정적 웹앱입니다. `index.html` 하나로 작동하며 외부 스크립트, 외부 데이터베이스, API 키가 필요 없습니다.

## 주요 기능
- 3일 단위 공부 계획, 과목별 체크리스트, 공부 타이머, 휴식 자동 시작
- 실제 지연시간을 이후 블록에 반영하는 유연한 시간표
- 기상/점심/저녁/취침/휴식 설정
- 새 3일 계획을 시작할 때 이전 날짜의 계획과 체크리스트를 `archivedDays`에 보관
- **기록** 화면에서 어제/오늘/원하는 날짜 선택, 공부시간·체크 내역 조회
- **선택 날짜 JPG·PDF** 직접 내려받기 (캔버스 기반, 외부 라이브러리 없음)
- **전체 JSON 백업/복원**: 과거의 모든 체크리스트, 타이머 기록, 설정 포함
- AI 탭은 실제 언어 모델이 아닌 **간단한 규칙 기반 데모**입니다.

## 데이터는 어디에 있나요?

`localStorage['gongsi-routine-demo-v2']`에 브라우저 내부 저장됩니다.
공부 기록은 GitHub 저장소/서버에 올라가지 않으며 GitHub 로그인과도 무관합니다.
다른 기기·브라우저와 동기화되지 않고 브라우저 저장 데이터가 삭제되면 기록이 사라집니다.
정기적으로 **설정 > 기록 백업(JSON)**을 사용하세요.
JPG/PDF는 읽고 보관하는 용도이며 **복원에는 사용할 수 없습니다**. 복원에는 JSON을 사용하세요.

## GitHub Pages 배포

1. 자신의 GitHub 계정에서 **새 public 저장소**(예: `gongsi-routine`)를 만듭니다.
2. 이 폴더의 `index.html`, `.nojekyll`, `README.md`를 저장소 `main` 브랜치의 최상위에 업로드합니다.
3. 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`를 선택하고 **Save**합니다.
5. GitHub Pages 배포가 완료되면 저장소 Settings → Pages에 표시되는 주소로 접속합니다.

주의: Pages는 **사이트 코드 공개**만 수행하며 개인 기록은 브라우저에만 저장합니다. 저장소에 실제 학습 기록 JSON을 올리지 마세요. `Settings > Pages`는 GitHub 관리 권한이 있는 계정에서 설정해야 합니다.

## 정식 서비스에서 추가할 작업

- GitHub / 이메일 로그인과 개인별 클라우드 동기화(예: Supabase)
- 개인 데이터 접근 권한 정책과 백업/복구
- 실제 AI 연동(서버 측 API 키 관리 필수, 공개 정적 HTML에 비밀키 삽입 금지)
- 모바일 웹 푸시 및 백그라운드 알림

## 로컬 테스트

폴더에서 `python -m http.server 8000` 후 브라우저에서 `http://localhost:8000`을 열면 됩니다.
